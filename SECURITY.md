# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

TrackOps handles financial records, inventory transactions, and sales receipts. We take security seriously.

If you discover a security vulnerability in TrackOps:
1. **Do not create a public GitHub issue.**
2. Send a detailed description of the vulnerability, including steps to reproduce, to the repository maintainer.
3. You will receive an acknowledgment within 48 hours.
4. A security patch will be prepared and tested before being published.

Thank you for helping keep TrackOps and its users secure!
